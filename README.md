# Firm Profitability Analysis (ANOVA in R)

This project analyzes how leverage, firm size, and liquidity affect firm profitability (ROA) using a 2³ factorial ANOVA design.

## Methods
- Factorial ANOVA (3 variables, interaction effects)
- Log transformation of ROA
- Median-based grouping (high/low)

## Key Findings
- Leverage has a significant negative relationship with ROA
- Firm size is positively associated with profitability
- Significant interaction between leverage and firm size
