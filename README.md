# Firm Profitability Drivers: Leverage, Size & Liquidity (R, ANOVA)

This project analyzes how financial structure and firm characteristics influence profitability (Return on Assets) using a 2³ factorial ANOVA design.

## Dataset
Firm-level financial ratios from Kaggle (via public GitHub source).

## Methods
- 2³ factorial design (Leverage, Firm Size, Liquidity)
- Log transformation of ROA
- Three-way ANOVA with interaction effects
- Median-based grouping (high vs low)

## Key Findings
- Leverage has a strong negative relationship with ROA
- Firm size is positively associated with profitability
- Liquidity has a weaker but significant effect
- Significant interaction between leverage and firm size
